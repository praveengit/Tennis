- Author every commit as `praveengit <praveen.batni@gmail.com>`. Set it
  first with `git config user.name "praveengit"` and
  `git config user.email "praveen.batni@gmail.com"`.
- Do not add `Co-Authored-By`, `Claude-Session` or any other Claude or
  Anthropic attribution lines to commit messages.
- Do not add "Generated with Claude Code" lines or session links to pull
